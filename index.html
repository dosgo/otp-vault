还没有账号

扫描网站「两步验证」页面上的二维码、手动输入 Base32 密钥，或从 Google Authenticator 批量导出账号。

安全提示：密钥只保存在本设备的本地存储中，不会上传。卸载应用或清除本地数据会一并删除，建议定期在「设置」里导出加密 ZIP 备份；启用 PIN 锁后数据会用 AES-GCM 加密。

添加账号

二维码 / 密钥 / otpauth 链接 / 谷歌验证器批量导出

点击下方按钮开启摄像头，把二维码放进框内

支持网站「两步验证」二维码，也支持 Google Authenticator「转移账号 → 导出账号」的二维码；导出有多张时可一次选中全部截图，或对着另一台手机连续扫。识别完全在本机完成。

高级选项（算法 / 位数 / 周期）

可粘贴二维码里的原始文本，也可一次粘贴多条（每行一条）；谷歌导出的 otpauth-migration 链接会自动走批量导入。

从 Google Authenticator 搬家

  1. 在谷歌验证器里点右上角 ⋮ →「转移账号」→「导出账号」
  2. 勾选要转移的账号，屏幕会出现一张或几张二维码
  3. 把二维码截图保存到手机，或直接对着另一台手机的屏幕连续扫

账号多时会分成多张二维码，需要按顺序全部读完才会汇总；少读几张也能先导入已读到的部分。

选择截图或粘贴链接后，这里会显示读取进度。

全部在本机解析，不联网、不上传。谷歌导出里的 HOTP（计数器型）与 MD5 账号会标记为「不支持」并跳过，其余都能完整导入。

备份与恢复

导出已加密

导出的 ZIP 会用你设置的密码加密，里面包含全部密钥。密码不会保存在应用里，忘记后无法找回，请单独记好；旧版明文 JSON 备份仍可导入。

关于

版本 1.2 · 遵循 RFC 6238（SHA1 / SHA256 / SHA512）· 支持 Google Authenticator 批量导出导入 · 备份支持 AES-256 / ZipCrypto 加密 ZIP · 全部运算在本机完成，应用不向任何服务器发送密钥或验证码。
